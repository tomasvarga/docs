[OpenCode](https://opencode.ai) is an open-source coding agent that supports multiple LLM providers. E2B provides a pre-built `opencode` template with OpenCode already installed.

## CLI

Create a sandbox with the [E2B CLI](/docs/cli).

```bash
e2b sbx create opencode
```

Once inside the sandbox, start OpenCode.

```bash
opencode
```

## Run headless

Use `opencode run` for non-interactive mode. Pass your LLM provider's API key as an environment variable — OpenCode supports `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, and [others](https://opencode.ai/docs/config/).

<CodeGroup>
```typescript JavaScript & TypeScript
import { Sandbox } from 'e2b'

const sandbox = await Sandbox.create('opencode', {
  envs: { ANTHROPIC_API_KEY: process.env.ANTHROPIC_API_KEY },
})

const result = await sandbox.commands.run(
  `opencode run "Create a hello world HTTP server in Go"`
)

console.log(result.stdout)
await sandbox.kill()
```
```python Python
import os
from e2b import Sandbox

sandbox = Sandbox.create("opencode", envs={
    "ANTHROPIC_API_KEY": os.environ["ANTHROPIC_API_KEY"],
})

result = sandbox.commands.run(
    'opencode run "Create a hello world HTTP server in Go"',
)

print(result.stdout)
sandbox.kill()
```
</CodeGroup>

### Example: work on a cloned repository

<CodeGroup>
```typescript JavaScript & TypeScript
import { Sandbox } from 'e2b'

const sandbox = await Sandbox.create('opencode', {
  envs: { ANTHROPIC_API_KEY: process.env.ANTHROPIC_API_KEY },
  timeoutMs: 600_000,
})

await sandbox.git.clone('https://github.com/your-org/your-repo.git', {
  path: '/home/user/repo',
  username: 'x-access-token',
  password: process.env.GITHUB_TOKEN,
  depth: 1,
})

const result = await sandbox.commands.run(
  `cd /home/user/repo && opencode run "Add error handling to all API endpoints"`,
  { onStdout: (data) => process.stdout.write(data) }
)

const diff = await sandbox.commands.run('cd /home/user/repo && git diff')
console.log(diff.stdout)

await sandbox.kill()
```
```python Python
import os
from e2b import Sandbox

sandbox = Sandbox.create("opencode", envs={
    "ANTHROPIC_API_KEY": os.environ["ANTHROPIC_API_KEY"],
}, timeout=600)

sandbox.git.clone("https://github.com/your-org/your-repo.git",
    path="/home/user/repo",
    username="x-access-token",
    password=os.environ["GITHUB_TOKEN"],
    depth=1,
)

result = sandbox.commands.run(
    'cd /home/user/repo && opencode run "Add error handling to all API endpoints"',
    on_stdout=lambda data: print(data, end=""),
)

diff = sandbox.commands.run("cd /home/user/repo && git diff")
print(diff.stdout)

sandbox.kill()
```
</CodeGroup>

## Connect with the OpenCode SDK

OpenCode includes a [headless HTTP server](https://opencode.ai/docs/server/) that you can control programmatically using the [`@opencode-ai/sdk`](https://opencode.ai/docs/sdk/) client. Start the server inside a sandbox, get the public URL with `sandbox.getHost()`, and connect from your application.

<Warning>
By default, every sandbox port is publicly reachable by anyone who knows the URL
(`https://{port}-{sandboxId}.e2b.app`) — including the OpenCode server started below,
which has no authentication of its own. Secure it with one (or both) of:

- **Traffic access token (recommended):** create the sandbox with
  `network: { allowPublicTraffic: false }` and send the `e2b-traffic-access-token`
  header with every request. This is enforced at the E2B ingress for **all** sandbox
  ports. See [Restricting public access](/docs/network/restrict-public-access).
  Note: this option can only be set at sandbox creation.
- **Server password:** set the `OPENCODE_SERVER_PASSWORD` environment variable and
  authenticate with HTTP basic auth (username `opencode`). This protects the OpenCode
  server only — other exposed ports stay public.
</Warning>

<CodeGroup>
```typescript JavaScript & TypeScript
import { Sandbox } from 'e2b'
import { createOpencodeClient } from '@opencode-ai/sdk'

const sandbox = await Sandbox.create('opencode', {
  envs: { ANTHROPIC_API_KEY: process.env.ANTHROPIC_API_KEY },
  network: {
    allowPublicTraffic: false, // require a per-sandbox token on all public URLs
  },
  lifecycle: {
    onTimeout: 'pause', // "pause" | "kill"
  },
  timeoutMs: 10 * 60 * 1000,
})

// All requests to the sandbox's public URLs must include this header
const authHeaders = { 'e2b-traffic-access-token': sandbox.trafficAccessToken! }

// Start the OpenCode server
sandbox.commands.run('opencode serve --hostname 0.0.0.0 --port 4096', {
  background: true,
})

// Wait for the server to be ready
const host = sandbox.getHost(4096)
const baseUrl = `https://${host}`
while (true) {
  try {
    const res = await fetch(`${baseUrl}/global/health`, { headers: authHeaders })
    if (res.ok) break
  } catch {}
  await new Promise((r) => setTimeout(r, 500))
}

// Connect to the server — the client sends the token on every request
const client = createOpencodeClient({
  baseUrl,
  headers: authHeaders,
})

// Create a session and send a prompt
const { data: session } = await client.session.create({
  body: { title: 'E2B Session' },
})
const { data: result } = await client.session.prompt({
  path: { id: session.id },
  body: {
    parts: [{ type: 'text', text: 'Create a hello world HTTP server in Go' }],
  },
})
console.log(result)
```
```python Python
import os
import time
import requests
from e2b import Sandbox

sandbox = Sandbox.create("opencode", envs={
    "ANTHROPIC_API_KEY": os.environ["ANTHROPIC_API_KEY"],
}, network={
    "allow_public_traffic": False,  # require a per-sandbox token on all public URLs
}, lifecycle={
    "on_timeout": "pause",  # "pause" | "kill"
}, timeout=10 * 60)

# All requests to the sandbox's public URLs must include this header
auth_headers = {"e2b-traffic-access-token": sandbox.traffic_access_token}

# Start the OpenCode server
sandbox.commands.run(
    "opencode serve --hostname 0.0.0.0 --port 4096",
    background=True,
)

# Wait for the server to be ready
host = sandbox.get_host(4096)
base_url = f"https://{host}"
while True:
    try:
        if requests.get(f"{base_url}/global/health", headers=auth_headers).ok:
            break
    except requests.ConnectionError:
        pass
    time.sleep(0.5)

# Create a session and send a prompt via the HTTP API
session = requests.post(f"{base_url}/session", headers=auth_headers).json()
result = requests.post(
    f"{base_url}/session/{session['id']}/message",
    headers=auth_headers,
    json={
        "parts": [{"type": "text", "text": "Create a hello world HTTP server in Go"}],
    },
).json()
print(result)
```
</CodeGroup>

### Alternative: password-protect the server

Instead of (or in addition to) the traffic access token, you can protect the OpenCode server itself with [`OPENCODE_SERVER_PASSWORD`](https://opencode.ai/docs/server/). OpenCode then requires HTTP basic auth with the username `opencode`. Note this guards only the OpenCode server — other sandbox ports remain publicly reachable unless you also restrict public traffic.

<CodeGroup>
```typescript JavaScript & TypeScript
const sandbox = await Sandbox.create('opencode', {
  envs: {
    ANTHROPIC_API_KEY: process.env.ANTHROPIC_API_KEY,
    OPENCODE_SERVER_PASSWORD: process.env.OPENCODE_SERVER_PASSWORD,
  },
})
// ...
const client = createOpencodeClient({
  baseUrl,
  headers: {
    Authorization: 'Basic ' +
      Buffer.from(`opencode:${process.env.OPENCODE_SERVER_PASSWORD}`).toString('base64'),
  },
})
```
```python Python
import os
import requests
from e2b import Sandbox

sandbox = Sandbox.create("opencode", envs={
    "ANTHROPIC_API_KEY": os.environ["ANTHROPIC_API_KEY"],
    "OPENCODE_SERVER_PASSWORD": os.environ["OPENCODE_SERVER_PASSWORD"],
})
# ...
auth = ("opencode", os.environ["OPENCODE_SERVER_PASSWORD"])
session = requests.post(f"{base_url}/session", auth=auth).json()
```
</CodeGroup>

## Build a custom template

If you need to customize the environment (e.g. pre-install dependencies, add config files), build your own template on top of the pre-built `opencode` template. Note that `OPENCODE_SERVER_PASSWORD` doesn't require a custom template — it can also be passed via `envs` at sandbox creation, as shown [above](#alternative-password-protect-the-server) — but a template lets you bake it in.

<CodeGroup>
```typescript JavaScript & TypeScript
// template.ts
import { Template, waitForPort } from 'e2b'

export const template = Template()
  .fromTemplate('opencode')
  .setEnvs({
    OPENCODE_SERVER_PASSWORD: 'your-password',
  })
  // Optional - start the OpenCode server on sandbox start
  .setStartCmd(
    'opencode serve --hostname 0.0.0.0 --port 4096',
    waitForPort(4096)
  )
```
```python Python
# template.py
from e2b import Template, wait_for_port

template = (
    Template()
    .from_template("opencode")
    .set_envs({
        "OPENCODE_SERVER_PASSWORD": "your-password",
    })
    # Optional - start the OpenCode server on sandbox start
    .set_start_cmd(
        "opencode serve --hostname 0.0.0.0 --port 4096",
        wait_for_port(4096)
    )
)
```
</CodeGroup>

<CodeGroup>
```typescript JavaScript & TypeScript
// build.ts
import { Template, defaultBuildLogger } from 'e2b'
import { template as openCodeTemplate } from './template'

await Template.build(openCodeTemplate, 'my-opencode', {
  cpuCount: 2,
  memoryMB: 2048,
  onBuildLogs: defaultBuildLogger(),
})
```
```python Python
# build.py
from e2b import Template, default_build_logger
from template import template as opencode_template

Template.build(opencode_template, "my-opencode",
    cpu_count=2,
    memory_mb=2048,
    on_build_logs=default_build_logger(),
)
```
</CodeGroup>

Run the build script to create the template.

<CodeGroup>
```bash JavaScript & TypeScript
npx tsx build.ts
```
```bash Python
python build.py
```
</CodeGroup>
